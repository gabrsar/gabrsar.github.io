Consulta rápida

Qual padrão aparece?

Primeiro procure um fator comum em todos os termos. Depois conte os termos e veja se algum destes padrões encaixa. A, B e C podem ser números ou expressões inteiras.

CasoO padrãoUm exemplo
Fator comum Algo multiplica todos os termos.AB + AC = A(B + C)6x² + 12x = 6x(x + 2)
Agrupamento Separe grupos com um fator em comum.AC + AD + BC + BD
= (A + B)(C + D)		x³ + 2x² + 3x + 6
= (x² + 3)(x + 2)
Diferença de quadrados Dois quadrados com sinal de menos.A² − B² = (A − B)(A + B)9x² − 25 = (3x − 5)(3x + 5)
Quadrado perfeito Confira o termo do meio: ±2AB.A² + 2AB + B² = (A + B)²
A² − 2AB + B² = (A − B)²		x² + 6x + 9 = (x + 3)²
4x² − 12x + 9 = (2x − 3)²
Trinômio com x² Procure soma s e produto p.x² + sx + p = (x + m)(x + n)quando m + n = s e mn = px² + 5x + 6 = (x + 2)(x + 3)
Soma de cubos O segundo fator troca o sinal do meio.A³ + B³ = (A + B)(A² − AB + B²)x³ + 8 = (x + 2)(x² − 2x + 4)
Diferença de cubos O segundo fator tem todos os sinais positivos.A³ − B³ = (A − B)(A² + AB + B²)x³ − 27 = (x − 3)(x² + 3x + 9)

Em uma tela pequena, deslize a tabela para ver as três colunas.

A conferência é sempre a mesma: multiplique os fatores usando a distributiva. Se todos os termos voltarem, a igualdade está certa. Talvez ainda dê para fatorar mais.

Expressão original

    A ideia por trás dos parênteses

    Os fatores são os lados.

    Um retângulo de lados (x + 2) e (x + 3) pode ser dividido em quatro partes. Somando as áreas, aparece x² + 5x + 6.

    Expandir é somar as quatro áreas. Fatorar é reencontrar os lados.

    Este desenho representa comprimentos positivos: x > 0. A identidade algébrica vale para todo x real.

    Laboratório de trinômios

    E quando a conta é outra?

    Escolha os coeficientes de ax² + bx + c. A ferramenta procura fatores inteiros e, quando precisa, mostra a forma exata com raízes reais.

    Coeficientes inteiros de −99 a 99
    Experimente:

    Trabalhamos com polinômios em x e coeficientes reais. A ferramenta aceita apenas os três coeficientes acima.

    Qualquer trinômio do 2º grau

    Se soma e produto não aparecerem de cabeça, calcule as raízes. Para a ≠ 0:

    Δ = b² − 4ac

    x₁, x₂ = (−b ± √Δ) / (2a)

    ax² + bx + c = a(x − x₁)(x − x₂)

    Δ > 0

    Duas raízes reais distintas, dois fatores lineares diferentes.

    Δ = 0

    Uma raiz real dupla. A forma é a(x − x₁)².

    Δ < 0

    Sem raízes reais: não se decompõe em fatores lineares com coeficientes reais.

    Raiz irracional também pode ser fator: x² − 2 = (x − √2)(x + √2). Já x² + 1 é irredutível nos reais. O conjunto de números permitido faz diferença.

    Para não cair na pegadinha

    Três cuidados que salvam a conta.

    O termo do meio existe.

    (A + B)² = A² + 2AB + B²

    O quadrado da soma tem +2AB. Em x² + 4x + 9, o meio precisaria ser 6x para virar (x + 3)².

    O sinal da raiz se inverte.

    raiz 3 → fator (x − 3)

    Se x = 3 zera o polinômio, então (x − 3) é um fator. Exemplo: x² − 9 = (x − 3)(x + 3).

    Cancele fatores, por inteiro.

    (x² − 9)/(x − 3) = x + 3

    Primeiro fatore o numerador. Só então cancele (x − 3), mantendo a condição x ≠ 3. Não se cancela um termo dentro de uma soma.

    Fatorar não é resolver uma equação.

    x² + 5x + 6 = (x + 2)(x + 3) é uma identidade: vale para todo x. Se o problema diz x² + 5x + 6 = 0, aí o produto precisa ser zero: x = −2 ou x = −3.
